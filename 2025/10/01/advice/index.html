# 厦门理工学院大一打算法路线

  1. 学校新手村尽早把 100 题全部刷完，大多数题要各位自己做出来 (培养你们前期思维能力) 但有些题有些像质数筛或者 bfs 涵盖一些算法知识的题可以去查 ai 或者浏览引擎上搜，期间如果觉得 C 语言已经比较熟练后可以去 C 语言 转 C++ 简单教程用两个小时的时间入门 CPP 的 STL 库以及其他语法，不用系统学 CPP，看完这个视频在前期基本够用，后期碰到不会再单独去学。此外，建议快速过一遍数据结构，可以开两倍速看，目的在于大致了解数据结构和算法，不用学代码实现。
  2. 新手村刷完后会对 C 和算法有一定的理解，之后可以开始系统学习算法，这里推荐去 AcWing 里报名算法基础课，视频总长度大概四十五个小时 (里面的内容有难度，大家需要反复琢磨，可能需要的时长远大于四十五个小时)，12 月份会有蓝桥杯选拔赛，差不多要在选拔赛前学个大概，建议你们在选拔赛前两周去 codeforces 上狂刷 div3 前 5 题和 div4 除去最后一题锻炼你们的思维能力。新生选拔赛你们大一单独排，在大一里面排名靠前就可以报销蓝桥杯省赛报名费。选拔赛过后就可以把 acwing 上的基础课全部刷完，期间也可以开始接触 codeforces 和 atcoder (关于 codeforces 和 atcoder 你们后面可以自行百度详细了解，也可以点 cf 和 atc 初略了解)。
  3. AcWing 上的算法基础课刷完后，可以选择一边跟 AcWing 上的算法提高课或者 leetcode 灵神题单 (里面的内容偏难，部分算法听不懂可以先放一放，但大部分仍然需要学会)，一边保持一定频率的实时参与 (rp) 和虚拟参与 (vp) 比赛。等刷完大部分提高课或 leetcode 题单后此时你们一定对算法有了自己一定的理解和见解，不再需要我们带路，但建议依然保持一定频率的实时参与，赛时看过的题目并有一定思考的再考虑补题，还有记住碰到不会的题尽量去查去学会它，问 AI 查百度逛博客园去 b 站找视频（灵茶山艾府，董晓，左程云等等）都可以只要你们能理解就行，如果真的真的花了一天还是不能理解就先放一放，过段时间或许你就理解了 (当然特别偏特别怪不常见的题先不管)。
  4. 最后欢迎大家加入我们学校的算法交流群：1051786877, 我们一起进步不用担心暂时实力低而不好意思，各位学长都很热情里面也会有近期比赛的通知。
